# vlayer Playground

Interactive web-based playground for trying vlayer HIPAA compliance scanning without installing anything.

**Live Demo:** https://play.vlayer.app (or your Vercel deployment URL)

## Features

- 🎨 **Monaco Editor** - Full-featured code editor with syntax highlighting
- 🔍 **Real-time Scanning** - Instant HIPAA compliance feedback as you type
- 📝 **Example Code** - Pre-loaded examples demonstrating common HIPAA violations
- 🎯 **Interactive Findings** - Click on findings to see detailed remediation guidance
- 📊 **Severity Badges** - Color-coded severity levels (Critical, High, Medium, Low)
- 🚀 **Zero Install** - Try vlayer directly in your browser

## About vlayer

vlayer is a CLI tool and platform that scans codebases for HIPAA compliance issues:

- **163+ detection rules** across 12 categories
- **HIPAA 2026 ready** - Covers all 15 new cybersecurity requirements
- **Compliance scoring** - Track your 0-100 HIPAA readiness score
- **Training module** - 10 modules, 45+ questions, verifiable certificates
- **Pro dashboard** - Historical scans, team management, PDF reports

## Development

This is a [Next.js](https://nextjs.org) project.

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to see the playground.

## Tech Stack

- **Next.js 16** - React framework with App Router
- **Monaco Editor** - VS Code's editor component
- **Tailwind CSS 4** - Utility-first CSS
- **TypeScript** - Type-safe JavaScript
